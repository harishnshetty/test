- Due to global customer base expansion (e.g., Australia), latency issues arose.
- Solution:

  - Reduced latency for customers globally.

#### [00:17:12 → 00:20:48] Challenge: Branching Strategy and Cost Optimization

- **Problem:**
  - No standardized branching strategy.
  - Developers had full push access, created many stale branches.
  - Resulted in higher organizational costs due to CI/CD pipeline running unnecessarily.
- **Solution:**
  - Evaluated branching strategies: **trunk-based vs. gitflow**.
  - Chose trunk-based branching due to simpler needs.
  - Restricted developer push access; only allowed pull requests.
  - Created documentation on:
    - Local testing using Docker images.
    - Running Kubernetes clusters locally.
  - Branching flow:
    - Main branch for active development.
    - Feature branches created from main.
    - Features merged during 3-month release cycle.
    - Release branch and tag created for releases.
    - Deployments go from dev → staging → production.
- **Outcome:**
  - Saved **over $50,000 in the last year**.
  - Improved developer workflow and local testing practices.
